# 🏡 난다펜션(Nanda Pension) 홈페이지 제작 및 운영

> **실제 운영 중인 서비스의 예약 플랫폼 구축부터 인프라 자동화 배포까지 전 과정을 경험한 프로젝트입니다.**
> * **서비스 주소:** [https://ndpension.com/](https://ndpension.com/)
> * **개발 기간:** 2025.07.01 ~ 2025.08.14 (약 1.5개월)

---

## 🛠 기술 스택

### Backend & Frontend
* **언어 (Languages)**
  * Java, JavaScript (ES6+), SQL, HTML5/CSS3
* **프레임워크 (Frameworks)**
  * Spring Boot
* **라이브러리 (Libraries)**
  * MyBatis, Thymeleaf
* **데이터베이스 (DB)**
  * MariaDB
* **형상 및 운영 관리**
  * **형상관리:** Git / GitHub (Issue 기반 브랜치 관리)
  * **CI/CD:** Jenkins (자동 배포 파이프라인 구축)
  * **컨테이너:** Docker (Jenkins, Tomcat 컨테이너 운영)
  * **인프라:** 개인 NAS (Synology/Linux 기반 서버 운영)
  * **도메인:** 호스팅케이알 (도메인 소유권 이전 및 DNS/SSL 관리)

---

## 🚀 주요 성과

1. **CI/CD 자동화 배포 및 형상 관리**
    * Docker와 Jenkins를 연동하여 소스 코드 병합 시 빌드부터 배포까지 전 과정 자동화
    * NAS 서버 내 WAR 파일 교체 및 톰캣 컨테이너 재시작 자동화로 운영 효율성 증대
    * GitHub Issue 기반 브랜치 전략을 통해 작업 단위별 독립성 및 코드 안정성 확보

2. **인프라 구축 및 도메인 관리**
    * 개인 NAS(Linux) 환경에서 컨테이너 기반 서버를 구축하여 물리적 서버 자원 관리 경험 보유
    * 기존 호스팅 업체로부터 도메인 소유권을 직접 이전하고 SSL 설치 및 DNS 설정 완료
    * 서버 가동 상태 모니터링 및 주기적인 로그 점검을 통한 안정적인 서비스 운영

3. **사용자 요구사항 대응 및 시스템 고도화**
    * 실사용자의 관리 편의성을 고려하여 자체 예약 시스템을 외부 전문 솔루션('떠나요') API로 전환
    * 비즈니스 로직 변경에 따른 유연한 아키텍처 수정을 통해 실사용자 만족도 제고
    * 유지보수 관점에서의 기능 개선 및 오류 대응 업무 수행
